# Stil de citare

Acest document definește modul în care cităm sursele juridice în knowledge library.

## Regula de bază

Orice afirmație juridică trebuie să includă citarea sursei lângă afirmația relevantă.

Format recomandat:

```md
Obligația se aplică operatorilor economici. **Sursă:** Art. 12 alin. (3).
```

## Exemple de citări

```md
Persoana obligată trebuie să depună declarația în termenul prevăzut de lege. **Sursă:** Art. 7 alin. (1).
```

```md
Excepția se aplică doar în situațiile expres menționate. **Sursă:** Art. 10 alin. (2) lit. b).
```

```md
Procedura este detaliată în capitolul dedicat aplicării măsurilor. **Sursă:** Capitolul III, Secțiunea 2.
```

## Citări incomplete sau neclare

Dacă sursa nu permite o citare exactă, marchează informația ca neclară:

```md
> [!WARNING]
> **NECLAR:** Textul sursă menționează obligația, dar nu indică termenul exact de aplicare.
```

## Ce trebuie evitat

- Nu grupa toate citările la finalul fișierului.
- Nu folosi citări vagi precum `conform legii`.
- Nu cita articole care nu susțin direct afirmația.
- Nu completa citările din memorie sau din surse externe neindicate în task.
