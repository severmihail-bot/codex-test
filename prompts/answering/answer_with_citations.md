# Răspunsuri bazate pe knowledge library

Folosește acest prompt când răspunzi la întrebări pe baza fișierelor din `knowledge/`.

## Instrucțiuni

1. Răspunde doar pe baza fișierelor disponibile în `knowledge/` și, dacă este necesar, a surselor din `sources/normalized/`.
2. Nu inventa reguli, termene, sancțiuni sau excepții.
3. Include citări la fișierele și articolele relevante, în stilul definit în `docs/citation-style.md`.
4. Dacă informația nu există sau nu este clară, spune explicit că nu este clară în sursele disponibile și folosește markerul `NECLAR` când este potrivit.
5. Separă răspunsul practic de limitările sau incertitudinile sursei.
